**[audiofilus](https://github.com/juanvillacortac/audiofilus)** is my main open source project: a pixel-art music player for Linux handhelds. The music keeps playing while you game, and sleep mode turns the screen off so you can control it from your pocket.

<p>
  <img src="https://raw.githubusercontent.com/juanvillacortac/audiofilus/main/site/img/player.webp" alt="audiofilus now playing" width="360">
  <img src="https://raw.githubusercontent.com/juanvillacortac/audiofilus/main/site/img/vis-lake.webp" alt="audiofilus visualizer" width="320">
</p>

- Written in Go with [Ebitengine](https://ebitengine.org): one binary for the UI, a background audio service and a CLI.
- Runs on Knulli, muOS, ROCKNIX, ArkOS and more through PortMaster, on Linux and Windows desktops, and on iPhone and iPad.
- Gapless playback, ReplayGain, parametric EQ with AutoEQ, crossfeed, internet radio, audiobooks, alarm and visualizers.
